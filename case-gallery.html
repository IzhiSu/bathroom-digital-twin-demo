Bathroom Digital Twin Case Gallery

This page documents case-based bathroom datasets used to support environment digitization, spatial interpretation, and reconstruction in the Bathroom Digital Twin framework. Each case acts as a structured evidence unit connecting field documentation with digital model development.

How to read this gallery

Each case is organized using the same structure: case overview, floor plan, 3D point cloud, contextual images, reconstruction model in Unity, and a short integration summary. Click the gray case header row to expand or collapse each case.

Case-based inputs

Floor plan, spatial documentation, point cloud data, and contextual images collected for each case.

Digital outputs

Reconstructed bathroom scenes in Unity used as the environmental basis for DT interaction and risk analysis.
